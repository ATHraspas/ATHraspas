# AI Creative Production OS (MVP)

Neo-brutalist, modüler, data-driven bir **creative production operating system** MVP.

## Çalıştırma
```bash
npm install
npm run dev
```

## MVP Özellikleri
- Hiyerarşik, collapsible sol panel navigasyon
- Ortak modül şablonu (neden, kullanım, senaryo, tools, sözlük, tips, hata, kaynak, ödev, checklist, rozet)
- Tracking pilot modülü (detaylı içerik + 10 ödev)
- Drawer ödev kartları + tik sistemi + localStorage progress
- 10/10 tamamlanınca `Tracking Operator` rozeti
- Tooltip mini sözlük
- Sağ tarafta modül bağlamlı asistan paneli
- Mobilde collapse sidebar + alt hızlı menü
- Genişletilebilir içerik veri modeli (`data/modules.ts`, `types/content.ts`)
